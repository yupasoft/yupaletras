# Yupaletras

Diapositivas de canciones de Yupasoft: proyecta las presentaciones de una carpeta de Google Drive sin descargarlas
y crea diapositivas nuevas pegando la letra de una canción. Se ingresa desde el portal: https://yupasoft.github.io/portal/

`pptxgen.bundle.js` es [PptxGenJS](https://github.com/gitbrent/PptxGenJS) 3.12.0 (licencia MIT), usado para descargar en PowerPoint.
